# imraaimmu.github.io

Personal portfolio for Imrankhan Mohamed Hanifa — senior software engineer, Java / Spring Boot / Kafka / AWS.

Live at **https://imraaimmu.github.io**

## Stack

- Next.js 15 (App Router) with `output: 'export'` — static HTML, no server
- React 19, TypeScript
- Hand-written CSS in `app/globals.css`. No CSS framework: the whole site is one page, so a utility framework would add a build dependency without reducing the amount of CSS.

## Local development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export into ./out
```

## Deployment

`.github/workflows/deploy.yml` builds on every push to `main` and publishes `out/` to GitHub Pages.

One-time setup in the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

### Why the odd bits in the config

| Thing | Reason |
| --- | --- |
| `output: 'export'` | Pages serves static files and cannot run the Next.js server. |
| `images: { unoptimized: true }` | The image optimiser needs a running server, which a static export does not have. |
| `out/.nojekyll` | Pages runs Jekyll by default, and Jekyll ignores paths starting with `_`, which would drop every asset in `_next/`. |
| `trailingSlash: true` | Emits `about/index.html` instead of `about.html`, so clean URLs resolve. |

## Content

Copy lives directly in `app/page.tsx`, with the repeated sections (metrics, skills, roles, notes) driven by arrays at the top of the file. Client engagements are described without internal system names.

`components/IdempotencyDemo.tsx` is an interactive walkthrough of a real defect from the FitTrack platform: an idempotency `operationId` scoped only to gym + member, combined with receipts that never expire, meant every visit after the first replayed a stored receipt and wrote nothing.
